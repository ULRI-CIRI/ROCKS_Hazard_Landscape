# ROCKS Hazard Landscape 
This repository contains the analysis and figure-generation workflows used in "The hazard data landscape of a global chemical collection." It includes the data processing, statistical analysis, and visualization code used to generate the study’s figures, with the project primarily implemented in R and supported by Python utilities.

## Structure
- `figures/` = figure-specific scripts
- `R/` = shared helper functions
- `run/` = scripts to build figures
- `data/` = local data inputs (not tracked unless noted)

## Disclaimer 
The code provided in this repository is for publication transparency. Some internal-only resources were used to query data that are publicly available in other formats.
