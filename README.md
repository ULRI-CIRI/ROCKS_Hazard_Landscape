# ROCKS Hazard Landscape 

R scripts and figure workflows for the hazard landscape manuscript.

## Structure
- `figures/` = figure-specific scripts
- `R/` = shared helper functions
- `run/` = scripts to build figures
- `data/` = local data inputs (not tracked unless noted)

## Disclaimer 

The code provided in this repository is for publication transparency only. Some internal-only resources were used to query data that is publicly available in other formats.
